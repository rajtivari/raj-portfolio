# Raj Tivari — Developer Portfolio

A cinematic personal portfolio built with React and Vite. The experience combines a scroll-led visual intro with sections for projects, skills, certificates, experience, and contact details.

## Sections
- Cinematic introduction
- Project showcase
- Technical skills
- Certificates
- Experience and education
- Contact

## Tech stack
- React
- Vite
- GSAP
- JavaScript
- CSS

## Run locally

Requirements: Node.js and npm.

```bash
git clone https://github.com/rajtivari/raj-portfolio.git
cd raj-portfolio
npm install
npm run dev
```

Create a production build:

```bash
npm run build
npm run preview
```

Run lint checks:

```bash
npm run lint
```

## Deployment

The project includes a GitHub Pages deployment script. Run `npm run deploy` after confirming the build and repository Pages settings.
